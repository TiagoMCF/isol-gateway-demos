# iSol Gateway Demos

Real, runnable examples of pointing everyday tools at a private
OpenAI-compatible gateway (the [iSol API](https://isollm.ai/api/)).

Every workflow here has real runs in the Actions tab, nothing mocked.

- `ai-review.yml`: AI code review on every push, answered by iSol 4.9
  through the iSol API. Guide: https://isollm.ai/blog/github-actions-own-gateway/
