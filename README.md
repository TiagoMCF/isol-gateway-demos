# iSol Gateway Demos

Real, runnable examples of pointing everyday tools at a sovereign
OpenAI-compatible gateway (the [iSol API](https://isollm.ai/api/)).

Every workflow here has real runs in the Actions tab — nothing mocked.

- `ai-review.yml` — AI code review on every push, answered by a model
  running on sovereign infrastructure. Guide: https://isollm.ai/blog/github-actions-own-gateway/
